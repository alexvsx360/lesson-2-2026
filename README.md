# מצגת אינטראקטיבית - שיעור 2: מבנה סמנטי, תוכן וטפסים

https://alexvsx360.github.io/lesson-2-2026/
## תיאור

שיעור 2 ממשיך את שיעור 1 ובונה את השלד והתוכן של דף נחיתה. הדגש הוא על HTML סמנטי, חלוקה נכונה לאזורים, ניווט, מדיה, רשימות וטופס הרשמה שמוכן להמשך עבודה עם JavaScript.

המצגת עצמה מדגימה **במהלך השיעור את שני הצעדים**:

- **רק `index.html`** — כל אזור מתווסף בהדרגה בתוך תצוגת "דפדפן" בתוך המצגת.
- **הוספת קטע מתאים ל-`css/style.css`** — מיד אחרי מודגם איך אותו החלק משתנה בעיצוב בסיסי ומקצועי.

קבצי ה-CSS של התלמיד נשארים בדרך כלל בתיקייה `css/style.css` בתוך פרויקט הדף, בעוד שקבצי העיצוב והלוגיקה של **המצגת** (`styles.css` ו-`script.js` בתיקיית `שיעור 2`) משמשים את ממשק המצגת בלבד.

## מה נלמד?

### חלק א': סמנטיקה וחלוקה
- שימוש ב-`header`, `main`, `section` ו-`footer`.
- להביא גם בהירות לשימוש ב-`div` (קופסת מבנה) ו-`span` (הדגשה או צביעה חלקית בתוך שורה).
- ההבדל בין תגיות סמנטיות לבין שימוש כללי ב-`div`.
- יצירת שלד לדף נחיתה.
- בניית תפריט ניווט עם `ul`, `li` ו-`a`.
- שימוש בקישורי עוגן כמו `#signup`.

### חלק ב': מדיה ותוכן
- בניית אזור Hero.
- הוספת תמונת Hero עם `img`.
- שימוש נכון ב-`alt`.
- יצירת אזור יתרונות בעזרת `ul`.
- שימוש ב-`ol` כאשר יש סדר של שלבים.

### חלק ג': טפסים, CSS ראשון והכנה ל-JS
- בניית טופס הרשמה.
- שימוש ב-`label`, `input` ו-`button`.
- סוגי input בסיסיים: `text` ו-`email`.
- חיבור `label` ל-input בעזרת `for` ו-`id`.
- דגש על `id` ייחודי וברור לכל שדה שנרצה לתפוס ב-JavaScript.
- קטעים לדוגמה ל-`css/style.css` שנלמדים יחד עם כל אזור בתוך המצגת.

## מבנה הקבצים

```text
שיעור 2/
|-- index.html          # קובץ המצגת
|-- styles.css
|-- script.js
|-- README.md
`-- landing-page/
    |-- index.html      # תוצר הדף המלא לתרגול בדפדפן
    |-- css/style.css   # העיצוב בקובץ נפרד מה-HTML (כמו בפרויקט אמיתי)
    `-- js/script.js    # הרחבת JavaScript בשלב דמו בסיסי בעתיד בשיעורים הבאים
```

## תוצר השיעור

בסוף השיעור בתיקיית `landing-page/` מופיע פרויקט מלא הניתן לפתיחה בדפדפן (מתוך שקופית 29 במצגת), ובמקבל נמשיך בהדרגתיות במצגת עצמה עם תצוגות מקוצרות ובדגש על שלבי HTML ו-CSS.
